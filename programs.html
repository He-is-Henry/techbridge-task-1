TechBridge Programs

What can you learn at TechBridge?

TechBridge programs are practical, project-based learning experiences. Pick a track, work on real tasks during the 30-day internship, and build skills you can apply in the real world.

Choose the track that matches what you want to build and learn. Use the filter to focus on one program.

Working with data and extracting insights

Data Analytics

This program introduces learners to practical data analysis: taking raw, messy data and turning it into clear information that supports better decisions.

Main skills

  • Spreadsheet analysis
  • Data cleaning
  • SQL
  • Data visualization
  • Business-focused analysis
What you'll practise
  • Cleaning and preparing data for analysis
  • Analysing and interpreting results
  • Working with tools such as Excel and SQL
  • Presenting findings through visualization and reporting
  • Practical projects to build your portfolio
Apply for Data Analytics
💻

Designing and building websites and web applications

Web Development

This program introduces learners to practical website development: structuring pages, styling them, adding behaviour, and putting finished work online.

Main skills

  • HTML
  • CSS
  • JavaScript
  • Git / GitHub
  • Building web projects
What you'll practise
  • Building and improving websites
  • Practising HTML, CSS, JavaScript and other relevant tools
  • Working on practical development tasks
  • Using GitHub to manage and showcase your projects
  • Deploying live projects
Apply for Web Development
